### ⭐ Featured Projects

**[Streetwise](https://github.com/ForgottenLight4415/NYC-Streetwise)** | NYC rental risk scoring tool | Built for NYC (NYPL x MLH) Hackathon 2026 | [Live Demo](https://nycstreetwise.vercel.app)  
Built the Express backend and rewrote the Next.js frontend. Scores buildings and blocks against citywide baselines, with a MongoDB caching layer that cut NYC 311 data response time from 3s to ~2ms on warm requests, a provider-agnostic AI explanation layer (local Ollama or Gemini, with a template fallback), and a 700-test Vitest suite.  
`Next.js` `Express` `MongoDB` `Ollama` `Gemini` `Vitest`

**[LunaFlow](https://github.com/atharvasalunke/period_cycle_planner)** | Cycle-aware productivity planner | Hackviolet 2026 | [Demo](https://youtu.be/91-5FK8gVN8)  
Built the Google Calendar and Tasks OAuth integration (Express and TypeScript, refresh tokens stored in PostgreSQL via Prisma) and the color-coded cycle-phase calendar in React.  
`React` `TypeScript` `Express` `PostgreSQL` `Prisma`

**[SentiMint](https://github.com/ForgottenLight4415/finscraper)** | Multi-agent stock analysis tool | Agent Hacks 2025 | [Demo](https://youtu.be/tFWt7iAZH40)  
Built `finscraper`, the standalone financial data package behind the analysis pipeline, exposed through a LangChain Tool interface with current price, trend data, and recent news retrieval, plus the Next.js frontend.  
`Python` `LangChain` `Next.js` `pytest`

**[URSA](https://youtu.be/RAQNqr2_Zi4)** | Real-time video surveillance analytics system (project lead) | [Demo](https://youtu.be/RAQNqr2_Zi4)  
Built a multi-stream DeepStream pipeline sustaining ~30 FPS across up to 6 concurrent 1080p feeds, running a PeopleNet model fine-tuned with NVIDIA TAO (~90% validation accuracy) as an INT8 TensorRT engine. Publishes five real-time analytics event streams to Kafka and includes a Flask operator interface with browser-based region and line-crossing configuration.  
`DeepStream` `TensorRT` `NVIDIA TAO` `GStreamer` `Kafka` `Flask`

**Publication:** [Enhancing Security Surveillance Through Business Intelligence with NVIDIA DeepStream](https://doi.org/10.1007/978-981-97-0293-0_7), Springer (LNDECT), 2024
